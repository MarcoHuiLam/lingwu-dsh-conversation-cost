# AI 聊一句多少钱？我给自己做了张小票

用 AI 写代码，难受的地方不是它偶尔写错，是我压根不知道一句话烧掉多少钱。

我想先把话说清楚：我不是要算到小数点后四位，我只是想知道「这一轮」大概花了多少。

我平时用 DeepSeek 跑 DSH（DeepSeek Harness）。同样一段对话，命中比例高的时候一轮几分钱，掉下来能翻好几倍。DSH 会把这一轮用了多少 token 摆给我看，但换算成人民币这件事它不做，每次都得自己估，估到后来我就懒得看了。

所以我打算给自己做个小东西，挂在每轮回复下面：

≈ ¥0.0312 · 54.4k tok · 命中 98.0% ▾

点开是明细：模型、这一轮算高峰还是空闲、未命中输入 / 缓存命中输入 / 输出各多少 token、单价多少、小计多少。

顺手把账户余额也放到了会话头上，点开能看到充值余额、赠送余额和更新时间，不用再翻设置。

我拿两个跑完的轮次对过账，token 数量和页面原生的「用量」胶囊对得上；金额是按官方价目算出来的应扣估算，不是账单流水。我的判断是，这类数字宁肯说清楚边界，也别让人拿去当账单对：法定节假日查不到，会按工作日记，可能偏高；一轮里换过模型的话，只能按第一个模型的单价折算。这些我都写在说明里了，我理解有人会真的拿它对账。

做成了 DSH 技能「凌雾DSH对话花费」，装完刷新页面就能用，Windows / macOS / Linux 都行，价格表可以自己改。仓库在 GitHub，协议 MIT。
